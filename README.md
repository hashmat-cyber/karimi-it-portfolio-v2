# Karimi IT Professional Portfolio v2

A new professional bilingual (English / Dari) Information Technology portfolio for Sayed Hashmat Karimi.

## Important
Each major section is a **separate route/page**, not one long scrolling page:
- /
- /about
- /education
- /skills
- /certificates
- /projects
- /achievements
- /goals
- /contact

## Run on Windows PowerShell
```powershell
npm.cmd install
npm.cmd run dev
```

The app uses React + Vite + React Router + Lucide icons. No backend, database, API key or authentication is required.

Personal photo is intentionally not included yet. The final CV/email/LinkedIn details can be connected later.
